# 과제 09: 모든 정점 쌍의 최단경로 탐색

## 1. 과제 개요

C 언어로 **정점 10개, 간선 20개**의 **가중치 무방향 단순 연결 그래프**를 무작위 생성하고, **Floyd–Warshall 알고리즘**을 이용해 서로 다른 모든 정점 쌍 **45개**의 실제 최단경로와 최단거리를 출력하는 프로그램입니다.

## 2. 파일 구성

- `main.c`: 그래프 생성, 검증, 최단경로 계산 및 출력 코드
- `README.md`: 구현 설명, 실행 방법, 실행 결과 및 요구사항 점검

## 3. 그래프 생성 방법

1. 정점 `0`~`9`를 준비하고 순서를 무작위로 섞습니다(Fisher–Yates shuffle).
2. 두 번째 정점부터 이미 연결된 정점 중 하나를 무작위 선택하여 간선을 추가합니다. 이렇게 **9개 간선으로 신장 트리(Spanning Tree)** 를 먼저 만들기 때문에 10개 정점이 모두 연결됩니다.
3. 이미 연결된 정점 쌍과 자기 자신을 연결하는 경우는 배제하면서, **11개 간선을 더 추가**하여 총 **20개**로 만듭니다.
4. 각 간선의 가중치는 `rand() % 100 + 1`로 **1~100 사이의 양의 정수**를 부여합니다.
5. 인접 행렬을 대칭으로 저장하여 **무방향 그래프**임을 보장합니다. 실제 간선이 없으면 0으로 기록합니다(가중치는 모두 양수이므로 구별 가능).
6. 출력 전에 간선 수, 간선 중복, 자기 루프, 가중치 범위, 행렬의 대칭성, **BFS 연결성**을 검사합니다.

## 4. 최단경로 탐색 방법

- **Floyd–Warshall 알고리즘**을 사용합니다.
- `dist[i][j]`: 정점 `i`에서 `j`까지의 최단거리
- `next[i][j]`: 최단경로에서 정점 `i` 다음에 방문할 정점
- 중간 정점 `k`를 경유하는 비용 `dist[i][k] + dist[k][j]`가 기존 값보다 작으면 `dist`를 갱신하고 `next[i][j] = next[i][k]`로 기록합니다.
- `next` 배열을 따라 이동하면서 `0 -> 2 -> 7 -> 4`와 같이 **실제 정점 순서를 복원**합니다.
- `u < v`인 경우만 출력하여 순서가 바뀐 동일 쌍은 중복 출력하지 않습니다. 따라서 결과는 `10 × 9 / 2 = 45`개입니다.
- 각 출력 경로에서 **모든 간선 가중치를 다시 더한 값**이 `dist[u][v]`와 일치하는지 검사하며, 오류가 있으면 프로그램을 실패로 종료합니다.

**시간 복잡도**: Floyd–Warshall `O(V³)` / **추가 공간 복잡도**: 거리 및 경로 복원을 위한 `O(V²)` (간선 목록은 별도 `O(E)`).

## 5. 컴파일 및 실행

### macOS / Linux (터미널)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main
./main
```

특정 시드로 실행 결과를 확인하려면:

```bash
./main 20261015
```

### Windows (PowerShell, GCC 설치 환경)

```powershell
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main.exe
.\main.exe
```

특정 시드로 실행하려면:

```powershell
.\main.exe 20261015
```

### 난수 시드 안내

- 인자를 주지 않으면 `time(NULL)`을 사용하여 **실행할 때마다 대체로 다른 그래프**가 생성됩니다.
- 시드를 직접 지정하면 **동일한 실행 환경 및 C 런타임에서 같은 결과**를 다시 얻을 수 있습니다.
- C 표준의 `rand()` 난수 수열은 운영체제/컴파일러의 C 런타임에 따라 다를 수 있어 **동일 시드라도 macOS와 Windows의 출력은 다를 수 있습니다**.

### 추가 테스트 결과

- `-std=c11 -Wall -Wextra -Wpedantic` 옵션으로 **컴파일 경고 없이 빌드**했습니다.
- 무작위 시드 **100개**를 사용해 생성된 그래프의 조건을 점검했습니다.
- 총 **2,000개 간선**의 범위·중복 여부와 그래프 연결성을 확인했습니다.
- 생성된 총 **4,500개 최단경로(100회 × 45쌍)** 의 거리 값을 별도의 **Dijkstra 알고리즘 계산 결과**와 대조했으며 모두 일치했습니다.

## 8. 결론

10개 정점, 20개 간선의 무작위 가중치 무방향 단순 연결 그래프를 생성하였으며, Floyd–Warshall 알고리즘을 이용해 총 **45개 정점 쌍의 최단경로와 최단거리**를 정확히 계산하고 복원했습니다. 경로에 포함된 간선 개수가 아닌 **가중치의 합**을 기준으로 최단경로를 선택하며, 복원한 각 경로의 가중치 합과 최단거리의 일치 여부도 검증했습니다.
